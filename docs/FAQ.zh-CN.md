# 推特/X 图片视频下载常见问题 — v1.3.0

[English](FAQ.en.md) · [安装教程](INSTALL.zh-CN.md) · [项目介绍](../README.zh-CN.md)

## 能下载推特原图吗？

工具请求 `pbs.twimg.com` 的 `name=orig` 尺寸，这是 X 提供的原图尺寸版本，不保证是作者未经处理的上传文件或相机 RAW。

## 能下载最高画质的 X 视频吗？

工具选择网页收到的媒体信息中最高码率、可下载的 MP4，不代表作者转码前的源视频。仅 HLS、直播或缺少媒体信息时可能无法下载，GIF 类内容通常保存为 MP4。

## 可以批量下载推特图片和视频吗？

支持单帖和批量下载：收集已加载帖子，或在设定轮数内滚动，选择后加入队列。不等于完整账号爬虫；本版没有整账号/账号资料归档，也没有原创、回复、转发、引用帖专用筛选。

## 需要 API Key 或第三方解析网站吗？

不需要。工具观察 X 网页已经请求的响应，从 X 媒体域名下载，不保存认证令牌、不上传已保存帖子，也不做统计上报。

## 视频为什么待解析或失败？

先启用工具再刷新 X，打开原帖、刷新并等待媒体加载后重试。只有 HLS、访问受限、帖子已删除或 X 响应结构变更时，可能没有可下载 MP4。工具会报错，不会把封面图冒充视频。

## 为什么有些文件会跳过？

默认跳过已经下载的媒体。想保存副本，可选单帖菜单的**重新下载全部**，或调整**设置 → 跳过已下载的媒体**。去重历史无法感知你之后删除了磁盘文件。重试通常只补之前失败的媒体，不重复成功文件。

## 怎么切换中英文？

入口是**设置 → 界面语言**，英文为 **Settings → Interface language**。跟随浏览器时中文浏览器使用中文，其余使用英文。手动选择会保存，即时切换保留队列和选择。X 帖子内容与底层系统/网络错误不会自动翻译。

## 安卓 Chrome 的油猴能运行吗？

本版没有通用安卓兼容承诺，需要按具体浏览器构建和油猴版本验证注入、媒体响应捕获、`GM_download`、权限及后台行为。桌面窄屏测试只证明布局，不证明手机执行环境。

## 文件和记录保存在哪里？

文件使用浏览器下载目录。扩展记录使用 `chrome.storage.local`，油猴使用脚本管理器的本地存储。两种形式不会自动迁移数据，变更配置或安装目录前请导出重要记录；本版没有导入界面。

## 实际测过哪些内容？

单元和独立 Chromium 测试使用模拟帖子及队列回报，检查解析、队列恢复、去重、导出、语言切换、设置/任务保留、严格 Trusted Types 与窄屏布局。演示另外通过浏览器保存生成 PNG 并核对字节。真实登录 X 媒体与安卓实机仍未验证。
