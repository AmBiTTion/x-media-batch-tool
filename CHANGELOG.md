# Changelog / 更新日志

## v1.3.0 — 2026-10-20

### English

- English / Simplified Chinese UI, browser-language detection, saved override, and live switching without restarting active tasks.
- Translated controls, task states, accessible labels, first-use tips, tool-owned errors and confirmations; localized Chrome name and description.
- Bilingual project titles, overview tables, FAQ, installation guides, screenshots and installation/usage videos.
- A startup fix for document-start injection before the document root exists.
- Language coverage and browser tests for live switching, retained tasks/selection, onboarding, and narrow layouts.
- No new Android compatibility or full-account archiving claim. Walkthroughs use a synthetic post and verify a locally generated PNG download.

### 简体中文

- 新增 English / 简体中文界面，首次跟随浏览器，支持手动保存与下载中即时切换。
- 翻译控件、任务状态、辅助标签、首次引导、工具自身错误与确认框；扩展名称和简介提供语言包。
- 优化双语标题、项目速览、FAQ、安装教程、截图及安装使用演示视频。
- 修复 document-start 注入时文档根节点尚未创建的启动问题。
- 新增语言覆盖和浏览器测试，核对切换时保留队列/选择、引导及窄屏布局。
- 未新增安卓兼容或整账号归档承诺；演示使用模拟帖子并验证本机生成 PNG 的下载。

## v1.2.0 — 2026-10-20 (GitHub release / GitHub 首次发布)

### English

- Download controls and save-type menu under each post, including a batch-selection checkbox.
- Collapsible panel with post, task, and settings tabs; light/dark and narrow-screen layouts.
- Sequential queue, progress, automatic retry, manual recovery, duplicate skipping, and forced re-download.
- JSON/CSV exports, optional TXT sidecars, filename presets, and persistent settings/history.
- Reproducible extension build, unit/browser tests, bilingual documentation, and unpacked-extension/userscript release assets.
- Known limits: actual Android compatibility and logged-in real-media downloads are unverified; full-account/profile archives and dedicated repost-type filters are not included.

### 简体中文

- 每帖下载按钮、保存类型菜单及加入批量复选框。
- 默认收起的帖子/任务/设置面板、深浅主题及窄屏布局。
- 顺序队列、进度、自动重试、手动恢复、去重和强制重下。
- JSON/CSV 导出、可选 TXT 正文、命名预设、设置与历史保存。
- 可复现构建、单元与浏览器测试、中英文说明、扩展与油猴发布文件。
- 已知限制：未验证安卓实机及登录账号真实媒体下载；不包含整账号/账号资料归档或转发类型专用筛选。
